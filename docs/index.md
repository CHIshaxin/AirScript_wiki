# AirScript

> 一个简单快速的轻量级脚本应用开发平台

入口：[产品介绍](guide/summary.md) · [API文档(1.0)](api/excel/workbook/overview.md) · [API文档(2.0)](apiV2/overview.md)

## 特性

### 云技术

基于云技术构建，可让您快速轻松地创建与金山文档 Office 文件交互的业务应用

### 在线编辑

我们在金山文档的组件中提供了代码编辑器，您的代码将会安全地运行在我们的服务端上

### JavaScript开发

您可以使用现代 JavaScript 语言编写逻辑代码，并可以调用 AirScript 内置强大的组件（表格）API 来构建特定场景的解决方案

### Intellisense

内置定制化的全局 Application 对象，编辑器智能提示，开发、调试、运行一条龙服务

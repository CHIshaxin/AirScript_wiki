# RectangleRight (属性)

代表渐变填充收敛到的点或矢量。可读/写。

## 说明

与 RectangleLeft、RectangleTop 和 RectangleBottom 一起使用。下表中列出了有效值。

| 属性 | 值 |
| --- | --- |
| RectangleLeft | 0-1 |
| RectangleRight | 0-1 |
| RectangleTop | 0-1 |
| RectangleBottom | 0-1 |

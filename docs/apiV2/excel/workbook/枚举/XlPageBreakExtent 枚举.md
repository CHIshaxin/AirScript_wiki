# XlPageBreakExtent 枚举

---

指定分页符是全屏应用还是仅应用在打印区域。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlPageBreakFull** | 1 | 全屏。 |
| **xlPageBreakPartial** | 2 | 仅在打印区域内。 |

# XlImportDataAs 枚举

---

指定从数据库返回数据的格式。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlPivotTableReport** | 1 | 以数据透视表的形式返回数据。 |
| **xlQueryTable** | 0 | 以查询表的形式返回数据。 |

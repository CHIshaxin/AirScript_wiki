# XlPortugueseReform 枚举

---

指定葡萄牙语拼写检查模式。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlPortugueseBoth** | 3 | 拼写检查器识别前期修订和后期修订拼写。 |
| **xlPortuguesePostReform** | 2 | 拼写检查器只识别后期修订拼写。 |
| **xlPortuguesePreReform** | 1 | 拼写检查器只识别前期修订拼写。 |

# XlConnectionType 枚举

---

指定数据库连接的类型。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlConnectionTypeODBC** | 2 | ODBC |
| **xlConnectionTypeOLEDB** | 1 | OLEDB |
| **xlConnectionTypeTEXT** | 4 | 文本 |
| **xlConnectionTypeWEB** | 5 | Web |
| **xlConnectionTypeXMLMAP** | 3 | XML 映射 |

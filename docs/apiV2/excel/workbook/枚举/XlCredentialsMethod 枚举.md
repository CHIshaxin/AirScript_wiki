# XlCredentialsMethod 枚举

---

指定所用凭据方法的类型。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **CredentialsMethodIntegrated** | 0 | 集成 |
| **CredentialsMethodNone** | 1 | 不使用凭据 |
| **CredentialsMethodStored** | 2 | 使用存储的凭据 |

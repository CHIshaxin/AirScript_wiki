# XlWebFormatting 枚举

---

指定将网页导入查询表时应用网页格式（如果有）的程度。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlWebFormattingAll** | 1 | 导入所有格式。 |
| **xlWebFormattingNone** | 3 | 不导入任何格式。 |
| **xlWebFormattingRTF** | 2 | 导入与 RTF 格式兼容的格式。 |

# XlSortMethodOld 枚举

---

指定在使用中文排序方法时如何排序。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlCodePage** | 2 | 按代码页排序。 |
| **xlSyllabary** | 1 | 按发音排序。 |

# XlSortOrientation 枚举

---

指定排序方向。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlSortColumns** | 1 | 按列排序。 |
| **xlSortRows** | 2 | 按行排序。这是默认值。 |

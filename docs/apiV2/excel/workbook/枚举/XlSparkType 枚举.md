# XlSparkType 枚举

---

指定迷你图的类型。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlSparkColumn** | 2 | 柱形图迷你图。 |
| **xlSparkColumnStacked100** | 3 | 盈亏图表迷你图。 |
| **xlSparkLine** | 1 | 折线图迷你图。 |

# XlThreadMode 枚举

---

指定多线程计算模式的控制方式。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlThreadModeAutomatic** | 0 | 多线程计算模式是自动的。 |
| **xlThreadModeManual** | 1 | 多线程计算模式是手动的。 |

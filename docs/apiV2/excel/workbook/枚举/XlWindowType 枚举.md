# XlWindowType 枚举

---

指定图表的显示方式。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlChartAsWindow** | 5 | 图表将在新窗口中打开。 |
| **xlChartInPlace** | 4 | 图表将在当前工作表中显示。 |
| **xlClipboard** | 3 | 将图表复制到剪贴板。 |
| **xlInfo** | -4129 | 已放弃使用此常量。 |
| **xlWorkbook** | 1 | 此常量只适用于 Macintosh。 |

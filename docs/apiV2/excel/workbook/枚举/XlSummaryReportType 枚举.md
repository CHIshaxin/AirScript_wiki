# XlSummaryReportType 枚举

---

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlStandardSummary** | 1 | 并排列出方案。 |
| **xlSummaryPivotTable** | -4148 | 在数据透视表中显示方案。 |

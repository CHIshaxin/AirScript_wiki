# 概要

AirScript の高度なサービスを使うと、開発者は最小限の設定で特定の公開 WPS Docs API に接続できます。 使い方は AirScript の組み込み関数に非常によく似ています。

AirScript は実行時に [認可フロー](#authorization-flow) を自動で処理します。 ただし、スクリプトでサービスを使うには [高度なサービスを有効化](#enable-advanced-services) する必要があります。この手順を省略すると、サービスが見つからないため **undefined** エラーになります。

## 高度なサービスを有効化する

高度なサービスを使うには、次の手順に従います。

1. **効率化** - **AirScript エディター** を開いて編集ページを表示します。
2. AirScript エディターのツールバーで **サービス** をクリックします。
3. **サービスを追加** をクリックします。
4. サービスを選び、**確定** をクリックします。

高度なサービスを有効化すると、オートコンプリートに表示されます。

## 認可フロー

AirScript は高度なサービスでプライベートデータにアクセスする際、ユーザーの認可が必要です。

### 実行権限の付与

AirScript は、スクリプト作成時の高度なサービス設定から認可スコープを決定します （例: 特定ファイルへのアクセスやネットワークアクセス）。スクリプトが認可を必要とする場合、ユーザーがスクリプトを実行すると認可ダイアログが表示され、 関係する権限の範囲が説明されます。

通常のコード変更では、ユーザーがスクリプトに付与した認可はクリアされません。開発者が高度なサービス設定を変更した場合（追加・変更・削除）、 そのスクリプトに対するユーザーの認可はクリアされ、次回実行時に認可フローが再度実行されます。

**備考**: **マイスクリプト** 配下のスクリプトはユーザーが完全に所有します。このカテゴリでスクリプトを実行しても認可フローは発動しません。

### 認可の取り消し

ユーザーは、認可済みスクリプトの認可を手動で取り消せます。手順は次のとおりです。

1. **効率化** - **AirScript エディター** を開いて編集ページを表示します。
2. ファイル共有スクリプトの一覧で取り消したいスクリプトを見つけ、**…** でその他操作を開きます。
3. **サービス認可を取り消す** をクリックします

## 利用制限

悪意のあるスクリプトを防ぐため、高度なサービスにはセキュリティ関連の制限があります。

- 高度なサービスの過剰利用により、スクリプト実行が異常利用を示す明確なエラーで失敗することがあります。
- [HTTP](HTTP.md) サービス利用時、IP アドレスを使ったリクエストは許可されず、ポートを指定したリクエストも許可されません。
- [HTTP](HTTP.md) サービス利用時、レスポンスボディは 2 MB に制限されており、超過するとエラーになります。
- [KSDrive.openFile](KSDrive.md#openfile-openinfo) で得た [File](KSDrive.md#file) オブジェクトを `close` を呼ばずに [KSDrive.openFile](KSDrive.md#openfile-openinfo) で再度使うと、 エラーがスローされます。

# AirScript 概要

WPS Docs AirScript は、シンプルで高速かつ軽量なスクリプトアプリケーション開発プラットフォームです。クラウド技術を基盤に構築されており、WPS Docs Office ファイルと連携する業務アプリケーションを迅速かつ容易に作成できます。

WPS Docs コンポーネント内にコードエディターを提供し、コードは当社サーバー上で安全に実行されます。モダンな JavaScript でロジックを記述し、AirScript の強力な組み込みコンポーネント（スプレッドシート）API を呼び出して、特定シナリオ向けのソリューションを構築できます。

AirScript は、このサービスを提供する先駆的なプラットフォームです。

## AirScript でできること

AirScript は現在、オンラインスプレッドシートおよび多次元表の二次開発プラットフォームとして機能し、プログラミングによるスプレッドシートデータの CRUD、セル書式の変更、プロパティの設定などの機能を提供しています。

#### ツールの利点

- ローカル環境の構築は不要で、ドキュメント内のクラウド上で直接スクリプトを開発できます。
- カスタマイズされたグローバル Application オブジェクトを組み込み、エディターのインテリセンス、開発・デバッグ・実行を一箇所で完結できます。
- プロパティの取得が同期型、メソッドの実行が同期型であり、従来の非同期呼び出しに伴う認知負荷を軽減します。
- 統合開発環境のおかげで、スケジュールタスクの作成、データの一括処理、ドキュメントの自動生成など、開発者はここで想像力を存分に発揮できます。

## AirScript の使い方

オンラインスプレッドシート KSheet を開き、「効率」タブに切り替え、下の二次ツールバーから「AirScript エディターツール」を探してクリックし、AirScript エディターを開きます。

**AirScript を始める：最初の Hello World スクリプトを実行する**

エディターを開いて最初のテストスクリプトを実行する手順は次のとおりです。

- オンラインスプレッドシートの KSheet を開く
- 画面上部のナビゲーションバーで **効率** タブに切り替える
- その下の二次ツールバーから **AirScript エディター** を探してクリックする
- エディターには既定で「HelloWorld」スクリプトが開きます。ウェルカムメッセージ、公式ドキュメントへのリンク、およびコードで別途指定しない限りスクリプトは既定で最初のワークシートで実行されるという重要な注意書きが含まれます
- 上部ツールバーの **実行** ボタンをクリックしてスクリプトを実行する
- エディター下部にリアルタイムの実行ログが表示され、スクリプト環境の初期化、実行開始、最後にログコンソールへ出力される「Hello, World!」メッセージが確認できます

これで AirScript 環境が正しくセットアップされ、より複雑な自動化スクリプトの作成に進める状態になったことを確認できます。

### エディターの機能

スクリプトエディターは左側と右側の 2 部構成です。左側はスクリプトファイルの管理エリア、右側はコーディングおよび実行エリアです。スクリプトの作成・削除・変更・実行およびランタイムログの生成に対応しています。

ドキュメント操作 API については、エディターに Application オブジェクトのシンタックスヒントが組み込まれており、ドキュメントとシンタックスヒントに基づいて必要な OpenAPI を直接記述できます。

機能の詳細：

- スクリプト管理
  - エディターの左側および右側上部の操作エリアで、コードファイルの作成・保存・削除・実行などの一般的な操作が可能です。
  - スクリプトファイルはクラウドに保存され、「マイスクリプト」と「ドキュメント共有スクリプト」に分かれます。マイスクリプトはアカウントに紐づき、ドキュメント共有スクリプトは現在のドキュメントに紐づきます。
- コード編集
  - コードエディターはオープンソースの `monaco editor` をベースにしており、ユーザーの操作は基本的に `VS Code` と同様です。
  - コードの保存
    - スプレッドシート：コードはローカルに自動保存されますが、クラウドには自動同期されません。ユーザーは手動で「保存」または「Ctrl+S」をクリックしてクラウドに同期する必要があります。未同期のコードファイルは、ファイル名の前に「小さな緑の点」が表示されます。
    - 多次元表：スクリプトの切り替えや開発ツールの閉じる操作で、コードが自動保存されクラウドに同期されます。
- 実行ログ
  - コード実行の情報を表示し、返された情報に基づいてスクリプトの実行状態と print の結果を確認できます。
  - コードにエラーがある場合は、エラー情報と位置が表示されます。位置をクリックすると、エディターが該当するエラーコードブロックへ移動します。

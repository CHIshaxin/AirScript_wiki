# AirScript

シンプルで高速かつ軽量なスクリプトアプリケーション開発プラットフォーム

- [はじめに](guide/summary.md)
- [API ドキュメント (1.0)](api/excel/workbook/overview.md)
- [API ドキュメント (2.0)](apiV2/overview.md)

## 機能

### クラウド技術

クラウド技術を基盤に構築されており、WPS Docs Office ファイルと連携する業務アプリケーションを迅速かつ容易に作成できます

### オンライン編集

WPS Docs コンポーネント内にコードエディターを提供し、コードは当社サーバー上で安全に実行されます

### JavaScript 開発

モダンな JavaScript でロジックを記述し、AirScript の強力な組み込みコンポーネント（スプレッドシート）API を呼び出して、特定シナリオ向けのソリューションを構築できます

### Intellisense

カスタマイズされたグローバル Application オブジェクトを組み込み、エディターのインテリセンス、開発・デバッグ・実行を一箇所で完結できます

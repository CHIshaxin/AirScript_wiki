# AirScript 2.0 とは

AirScript 1.0 のスクリプトは、一般的なドキュメント自動化ニーズをカバーしています。一方で、API の網羅性、実行パフォーマンス、高度な JavaScript 構文のサポートなどに限界が残っていました。これらの制約を克服するため、AirScript 2.0 を導入しました。

AirScript 2.0 は新しいアーキテクチャを採用し、機能とパフォーマンスの面で大きく進化しています。API は WPS JS マクロと完全に整合し、実行は高速化され、モダンな JavaScript 構文を完全にサポートします。

AirScript 1.0 の API のほとんどは AirScript 2.0 でも動作しますが、バージョン間で API 定義が衝突するものもあるため、完全な互換性はありません。スクリプトのランタイムバージョンは `1.0` と `2.0` で識別する必要があります。AirScript 2.0 は大きなアップグレードであり、一部の API は AirScript 1.0 と互換ではありません。

# AirScript 2.0 の主な特長

### ✔️ WPS JS マクロとの完全互換

AirScript 2.0 は WPS JS マクロと完全互換で、2,000 以上の API（1.0 の約 4 倍）を提供し、構築できる範囲が大きく広がります。単純な作業の自動化から複雑なスクリプトの開発まで、AirScript 2.0 で対応できます。新しい API モデルを学び直す必要はなく、WPS とオンラインスプレッドシートで同じ API を使ってスクリプトを開発できます。

### 🚀 高速な実行

AirScript 2.0 では論理実行と API 呼び出しを最適化しており、スクリプトはより効率的に動き、応答も速くなります。特に API を頻繁に呼び出す大規模なスクリプトで効果が顕著です。例として、アクティブシートの列 1 の先頭 1,000 セルをループして前後の空白をトリムし値を書き戻す処理は、2.0 では 1.0 の約 2 倍の速さで実行できます。

> 1.0 と 2.0 のスクリプトをそれぞれ用意し、次のコードを実行すると、2.0 でのパフォーマンス向上を体感できます。

```javascript
// アクティブシートの列 1 の先頭 1,000 セルの前後空白をトリムし、実行時間をログ出力
const start = Date.now();

const sheet = ActiveSheet;
for (let i = 1; i <= 1000; i++) {
  const cell = sheet.Cells(i, 1);
  cell.Value2 = cell.Text.trim();
}

console.log(Date.now() - start);
```

### 🌐 モダンな JavaScript 構文の完全サポート

AirScript 2.0 は、`await` / `async`、`Promise`、`class` など（1.0 では未サポート）、モダンな JavaScript 構文を完全にサポートし、より現代的で生産性の高い開発体験を提供します。複雑なスクリプトの記述と保守がしやすくなります。

# 対応シナリオ

AirScript 2.0 は、AirScript 1.0 ができることすべてをカバーする設計です。第 1 フェーズではワークシート向けシナリオがサポートされ、Databook の API はまだ利用できません。Databook 向けのスクリプトの場合は、当面 AirScript 1.0 の利用を継続してください。2.0 への Databook API の追加は段階的に進めます。

> AirScript 2.0 は現在ベータ版です。今後のリリースで API 機能が順次拡充されます。

|  | AirScript 1.0 | AirScript 2.0 |
| --- | --- | --- |
| ワークシート | API（500 以上） | API（2,000 以上） |
| Databook | API | API（近日対応） |
| 高度なサービス | ネットワーク API<br>クラウドドキュメント API<br>メール API<br>データベース API | ネットワーク API<br>クラウドドキュメント API<br>メール API（近日対応）<br>データベース API（近日対応） |

# AirScript 2.0 の使い方

> 多次元表は Databook のサポートに依存しており、現時点では未対応です。

### 2.0 スクリプトの作成方法

1. AirScript スクリプトエディターを開く

**新しい AirScript 2.0 スクリプトの作成方法**

まず、メインメニューから専用のスクリプトエディターを開きます。

- 画面上部のナビゲーションバーで **効率** タブをクリックします
- 二次ツールバーの **高度な開発** ドロップダウンメニューを開きます
- ドロップダウンから **AirScript スクリプトエディター** を選択します

これにより、1.0 と 2.0 の両方のスクリプトを作成・編集・実行できるフル機能のスクリプトエディターが起動します。

2. スクリプトを作成する（共有ドキュメントのスクリプト／マイスクリプト）

`+` をクリックして、直接 2.0 スクリプトを作成できます。

ドロップダウンメニューからスクリプトのバージョンを選ぶこともできます。新しいスクリプトを作成するときは、左サイドバーのプラス記号（+）の横にある小さなドロップダウン矢印（「ドキュメント共有スクリプト」の横）をクリックして、使用するバージョンを明示的に選べます。

次の 2 つのオプションがあります。

- **AirScript 2.0 Beta（推奨）**：2,000 を超える API 呼び出しに対応し、クライアント側スクリプト構文との完全な互換性があり、最新の機能とパフォーマンス改善が利用できます
- **AirScript 1.0**：API の対応範囲が限定的で、旧来のレガシースクリプトの保守にのみ推奨されます

「マイスクリプト」で作成するスクリプトでも、バージョン選択の手順は同じです。

> 「マイスクリプト」の場合も手順は同じです。

### 2.0 の API ドキュメントの参照方法

API ドキュメントには 1.0 版と 2.0 版があり、バージョンごとに API が異なります。2.0 のドキュメントは [API ドキュメント（2.0）](overview.md) を参照してください。

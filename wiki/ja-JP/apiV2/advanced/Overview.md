# 概要

AirScript の高度なサービスを使うと、開発者は最小限の設定で特定の公開 WPS Docs API に接続できます。 使い方は AirScript スクリプトの組み込み関数に非常によく似ています。

AirScript はランタイムで[認可フロー](#authorization-process)を自動処理します。 一方で、スクリプトで利用する前に[高度なサービスを有効化](#enable-advanced-services)する必要があります。この手順を省略すると、サービスが見つからないため **undefined** エラーが発生します。

## 高度なサービスを有効にする

高度なサービスを使うには、次の手順に従ってください。

1. **効率化** - **AirScript エディターツール**を開き、エディターページを表示します。
2. AirScript エディターツール上部の **サービス** をクリックします。
3. **サービスを追加** をクリックします。
4. サービスを選び、**確定** をクリックします。

高度なサービスを有効にすると、オートコンプリートに表示されます。

## 認可フロー

AirScript は高度なサービスでプライベートデータにアクセスするために、ユーザーの認可を必要とします。

### 実行権限の付与

AirScript は、開発者がスクリプトを書くときの高度なサービス設定に基づいて認可範囲を決定します （例：指定ファイルやネットワークへのアクセス）。スクリプトが認可を要する場合、ユーザーがスクリプトを実行するときに認可ダイアログが表示され、 当該スクリプトに関わる認可範囲が説明されます。

通常のコード変更では、スクリプトに対するユーザーの認可はクリアされません。ただし、開発者が高度なサービス設定を変更した場合（追加・変更・削除）、 スクリプトに対するユーザーの認可はクリアされ、スクリプト実行時に再度認可フローが走ります。

**備考**：**マイスクリプト**のスクリプトはユーザーが完全に所有しており、このカテゴリのスクリプトを実行するときは認可フローを起動する必要はありません。

### 認可の取り消し

ユーザーは次の手順で、認可済みスクリプトの認可を手動で取り消せます。

1. **効率化** - **AirScript エディターツール**を開き、エディターページを表示します。
2. ドキュメント共有スクリプトの下で、認可を取り消したいスクリプトを見つけ、**…** をクリックしてその他の操作を表示します。
3. **サービス認可を取り消す** をクリックします。

## 利用上の制限

悪意のあるスクリプトをユーザーに提供しないよう、セキュリティ上の理由から高度なサービスにはいくつかの制限があります。

- 高度なサービスを過度に頻繁に使用する場合。スクリプトは明確なエラーを投げ、異常な呼び出しをユーザーに通知します。
- [HTTP](/docs/ja-JP/apiV2/advanced/HTTP.html) サービス使用時、IP アドレス宛のリクエストは禁止され、ポートを指定したリクエストも禁止されます。
- [HTTP](/docs/ja-JP/apiV2/advanced/HTTP.html) サービス使用時、受信できるメッセージボディの最大サイズは 2M です。2M を超えるとエラーが発生します。
- [KSDrive.openFile](/docs/ja-JP/apiV2/advanced/KSDrive.html#openfile-openinfo) で取得した [File](/docs/ja-JP/apiV2/advanced/KSDrive.html#file) オブジェクトを閉じていない場合、 再度 [KSDrive.openFile](/docs/ja-JP/apiV2/advanced/KSDrive.html#openfile-openinfo) を呼ぶとエラーが発生します。

# ビュー設定

開発経験のない相手にもスクリプトを渡しやすくするため、パラメーターの可視化設定を用意しています。スクリプトのツールバーから `ビュー設定` をクリックすると、パラメーター配置ツールを開けます。`form` フォームとスクリプトを組み合わせて設定すると、すばやく操作できるツールを生成できます。

## ビューとスクリプトの関係

- ビューで設定したフォームのパラメーターは、スクリプトエディター内で `Context.argv` の下にマウントされ、プログラムから直接参照できます。`Context` は `Application` と同様のグローバル変数です。
- ビューで設定したパラメーターは、コードエディターでリアルタイムにシンタックスヒントとして表示されます。`Context.argv` と入力すると、設定したパラメーターが確認できます。
- プレビュービューで、ビュー内の `スクリプトを実行` ボタンをクリックすると、フォームで入力したパラメーター付きでスクリプトが実行され、ログはコードエディターのログ欄に出力されます。

## 簡単な利用例

#### 1. パラメーターを設定する

ビュー設定を開き、次のパラメーターを追加します。

| パラメーター名 | 変数名 | 変数の型 | 入力ヒント |
|---|---|---|---|
| シートを選択 | sheet | string | シート名を入力: "sheet1" |
| セルを選択 | range | string | セルを入力: "A1" |
| 値を入力 | value | string | 設定する値を入力 |

#### 2. コードを入力する

```js
Application.Sheets.SelectByName(Context.argv.sheet).Activate()
Application.Range(Context.argv.range).Value=Context.argv.value
```

#### 3. 編集結果

手順 1 と 2 を完了すると、編集結果は次のとおりです。

パラメーター付きスクリプトの先頭 2 行を書き終えると、AirScript エディターはコード内で定義した `Context.argv` パラメーターを自動的に検出します。入力に応じてスマートなコード補完ポップアップが表示され、利用可能なすべてのパラメーター（`sheet`、`range`、`value`）とその型ヒントが示されます。

同時に、エディター右側にビジュアルな設定パネルが生成されます。このパネルを使えば、コードを書かずにスクリプトを実行できます。ユーザーは必要な値を入力するだけでよく、対象のワークシートの選択、セル範囲の指定、設定する値の入力ができます。ワンクリックでパラメーターを追加したり、既存のパラメーターをすべてクリアしたりしてから、「スクリプトを実行」をクリックしてテストすることもできます。

#### 4. 実行結果

`プレビュー` をクリックし、テスト用の値を入力してスクリプトを実行すると、結果は次のとおりです。

スクリプトをテストするときの動作は次のとおりです。

1. 右側の設定パネルで「プレビュー」ボタンをクリックします
2. テスト用の値を入力します。対象のワークシートとして `Sheet1` を選び、セル範囲に `A1:B2` と入力し、設定する値として `Test` を入力します
3. 「スクリプトを実行」をクリックします

スクリプトはすぐに実行され、下部にリアルタイムのログが表示され、初期化・開始・完了までの実行過程が確認できます。結果はスプレッドシートに直接反映されます。指定どおり、A1 から B2 までのセルすべてに「Test」という文字列が入力されます。

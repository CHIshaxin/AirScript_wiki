# XlConsolidationFunction 枚举

---

指定分类汇总函数。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlAverage** | -4106 | 平均。 |
| **xlCount** | -4112 | 计数。 |
| **xlCountNums** | -4113 | 只计数数值。 |
| **xlMax** | -4136 | 最大值。 |
| **xlMin** | -4139 | 最小值。 |
| **xlProduct** | -4149 | 乘。 |
| **xlStDev** | -4155 | 基于样本的标准偏差。 |
| **xlStDevP** | -4156 | 基于全体数据的标准偏差。 |
| **xlSum** | -4157 | 总计。 |
| **xlUnknown** | 1000 | 未指定任何分类汇总函数。 |
| **xlVar** | -4164 | 基于样本的方差。 |
| **xlVarP** | -4165 | 基于全体数据的方差。 |

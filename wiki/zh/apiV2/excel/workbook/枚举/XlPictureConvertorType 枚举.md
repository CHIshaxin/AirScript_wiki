# XlPictureConvertorType 枚举

---

指定图形的转换方式。

| 名称 | 值 | 说明 |
| --- | --- | --- |
| **xlBMP** | 1 | 与 Windows 2.0 版兼容的位图 |
| **xlCGM** | 7 | 计算机图形图元文件 |
| **xlDRW** | 4 | DRW |
| **xlDXF** | 5 | DXF |
| **xlEPS** | 8 | 封装的附录 |
| **xlHGL** | 6 | HGL |
| **xlPCT** | 13 | 位图图形（Apple PICT 格式） |
| **xlPCX** | 10 | PC 画笔位图图形 |
| **xlPIC** | 11 | PIC |
| **xlPLT** | 12 | PLT |
| **xlTIF** | 9 | 标记图像格式文件 |
| **xlWMF** | 2 | Windows 图元文件 |
| **xlWPG** | 3 | WordPerfect/DrawPerfect 图形 |

A simple, fast, and lightweight scripting application development platform

## Features

### Cloud Technology

Built on cloud technology, enabling you to quickly and easily create business applications that interact with WPS Docs Office files

### Online Editing

We provide a code editor within WPS Docs components, and your code will run securely on our servers

### JavaScript Development

You can write logic code using modern JavaScript, and call AirScript's powerful built-in component (spreadsheet) APIs to build solutions for specific scenarios

### Intellisense

Built-in customized global Application object, editor intelligent prompts, development, debugging, and execution all in one place

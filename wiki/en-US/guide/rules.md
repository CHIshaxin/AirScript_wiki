# Scripting Language

AirScript uses standard [JavaScript](https://developer.mozilla.org/en-US/docs/Learn/Getting_started_with_the_web/JavaScript_basics) for scripting and supports most ES6 syntax.

## Built-in Global Objects

#### Document OpenAPI Object `Application`

Application is the document OpenAPI object. Based on different WPS Docs document types, different Application object properties will be generated, which can be directly referenced in the code editor.

#### Script Context Object `Context`

Context is the script runtime context object. It is responsible for mounting some properties related to script execution, such as content generated by `view`, `configuration`, etc., which can be directly referenced in the code editor to facilitate the construction of the overall application.

## Unsupported Syntax

### Class

```javascript
class C{
    private a; // Unexpected token
    public b(){
        return this.a;
    }
}
```

### Defining Methods Directly in Object

```javascript
let obj = {
    sayHello(){ //Unexpected token
        console.log("hello")
    }
}
obj.sayHello()
```

### import, export

```javascript
import os from 'os' // SyntaxError
export default os // SyntaxError
```

### ?.

```javascript
function f(argv){
    console.log(argv?.toString()) // Unexpected token
}
```

### await

```javascript
async function f() {
    await new Promise((resolve)=>{ // Unexpected token
        resolve("")
    })
}
```

### yield

```javascript
function* foo(index) {
  while (index < 2) {
    yield index; // Unexpected token
    index++;
  }
}

const iterator = foo(0);

console.log(iterator.next().value);

console.log(iterator.next().value);
```
